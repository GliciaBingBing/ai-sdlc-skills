# 护栏4 · 一键还原（Rollback Gate）

## 规则
- 回退粒度为**版本级手动快照**：在重要节点由你（或开发 AI 在关键节点）手动触发一次快照。
- 上轮产出有问题（缺陷/越界/读不懂）→ 触发回退到上一版本快照，在干净基线重新派发。
- 回退**不丢失**已迭代成果：原版本快照保留，可随时切回。

## 用法
- 存盘：`snapshots/<version>/` 下保存当前可运行版本（建议每次「认为这轮稳了」时存一次）。
- 回退：触发回退 → 恢复到指定 version；原 version 不删。
- **验证 harness 稳定前先手动，不自动**；稳定后可升级为自动快照。

## 边界
- 无快照可回退 → 提示「请先手动存盘」，不执行回退。
- 工作区有未快照改动 → 提示先存盘或丢弃后再回退。
- 回退只是切换基线，不删任何已有版本。
