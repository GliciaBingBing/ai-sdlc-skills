# 模块地图（人读视图）

> 这是给你维护的视图。你只需要**用大白话列出产品有哪些功能模块**，
> 剩下的「功能 → 代码目录」映射，由 AI 读代码库自动完成，你完全不用碰文件/目录。

## 怎么填（只写功能名，不用管代码）
按「一个功能模块 = 一段」列出即可，比如：
- 账号管理：用户登录、注册、资料编辑
- 订单：下单、查单、退款
- 消息通知：推送、站内信

## AI 怎么把功能映射到代码目录（机制）
你给功能名后，AI 会：
1. 扫描仓库目录结构（列目录、读路由/模块入口）
2. 判断每个功能大致落在哪些目录（如「账号管理」→ src/routes/account、src/models/account）
3. 把映射写进 `module-map.yaml`（AI 解析用）
4. 之后每次提交，AI 自动把新文件归到对应模块并更新 yaml

你不用懂代码、不用写目录——**你只管说「有哪些功能」，AI 负责定位代码**。

## 注意
- 粒度用「目录级」即可。
- 你偶尔复核一下这份 md 和 yaml 是否对得上就行。
- 想新增模块，直接在这里加一段，AI 会同步进 yaml。
