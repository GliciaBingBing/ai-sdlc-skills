# PRD · 忘记密码（节选，对应 MOD-001 账号管理）

## 用户故事
1. 作为未登录用户，我想在登录页点「忘记密码」，以便进入重置流程。
2. 作为用户，我想输入注册邮箱收到重置链接，以便安全地重设密码。
3. 作为用户，我想用链接里的 token 设新密码，以便完成重置。

## 验收标准
- AC1：登录页存在「忘记密码」入口，点击进入 `/reset/request`。
- AC2：输入已注册邮箱 → 发送含有时效 token 的邮件；返回「已发送」不泄露账号是否存在。
- AC3：点链接 → `/reset/confirm?token=...` 可设新密码；token 单次有效、15 分钟过期。
- AC4：新密码强度校验（≥8 位，含大小写+数字）。

## 范围边界
- 仅改 **账号管理（MOD-001）**：`src/routes/account`、`src/models/account`。
- 不动订单 / 消息通知等其他模块（护栏2 范围自检依据）。
